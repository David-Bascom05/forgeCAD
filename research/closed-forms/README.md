# Closed-form intersections: where the coefficients come from

## What was derived, and where the code uses it

- **Surface-pair turning points** (`crates/forge-geom/src/meet.rs`, `meet_gen.rs`): the quartic
  discriminant, the half-angle quartic of a degree-2 trigonometric polynomial and the torus along
  a line. Generated by `tools/sympy/meet.py`, which writes `meet_gen.rs` and asserts the two
  degenerate cases meet.rs relies on (equal crossing cylinders, sphere on cylinder). Committed
  with the code in 6977e3a; rerunning it on main reproduces `meet_gen.rs` byte for byte.
- **Quartic root counts** (`meet.rs`, the count from `quartic_disc`): disc < 0 gives two real
  roots; disc > 0 four when P = 8ac - 3b^2 < 0 and D = 64a^3e - 16a^2c^2 + 16ab^2c - 16a^2bd - 3b^4
  < 0, else none (Rees, 1922; the standard table for a quartic's real roots). From the literature
  in fce8490; `check.py` tests the rule against exact real-root counts on 2000 random quartics.
  The 1e-6 and 1e-9 cut-offs below which it falls back to finding roots were not measured
  (no record).
- **Parabolas (text glyphs, 8e817af)**, derived by hand at the time, no script kept:
  - `parabola_quadric` (`intersect.rs`): a quadric along P(t) = o + k t^2 x + t y is a quartic;
  - `parabola_wall` (`ruled/meet.rs`): a parabola in a plane parallel to an extruded parabolic
    wall meets it where X(t) - ka Y(t)^2, a quartic, vanishes;
  - `parabola_nearest` (`ruled.rs`): (P - q).P' = 0 is the depressed cubic
    2k^2 t^3 + (1 - 2k x) t - y, solved by Cardano (trigonometric form for three real roots).

  `check.py` (recreated 2026-11-01) re-derives each set of coefficients symbolically and checks
  Cardano's roots, as the code takes them, against the cubic in 60-digit arithmetic.

## How to rerun

```
fbuild python3 tools/sympy/meet.py              # rewrites crates/forge-geom/src/meet_gen.rs; git diff shows nothing
fbuild python3 research/closed-forms/check.py   # five "ok" lines
```
Both need sympy (1.14 used); it is an offline tool, never a build dependency.

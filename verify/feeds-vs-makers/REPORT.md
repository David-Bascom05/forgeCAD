# Our feeds and speeds against the tool makers' published numbers

Generated by `cargo run -p feeds-vs-makers` (verify/feeds-vs-makers). Ratios are ours / theirs; each cell is the median (10th–90th percentile, count). Ours (presets OFF): forge_tooling::resolve with the maker's own preset off, i.e. the generic default (the lower quartile of the tool's class, below), at the maker's own ae/ap, no machine clamps; presets ON is its own section. Theirs: CAM-HAAS's cited raw rows (research/cam/tooling/raw/*.json; each row's URL is in rows.tsv). Ranges are taken at their middle.

## Summary

- "Are we the worst of all worlds by averaging manufacturer specs?" For a tool with no maker data the default was one pooled median per material group. It is now the **lower quartile (P25) of the tool's class** (material group × op class × maker tier × flutes × coating × helix, opened up where a class has under 10 rows or one maker), with the class's min/P25/median/max shown next to the value so it can be pushed up knowingly. A tool with maker presets uses them first (next section but one).
- The independent check (each maker against classes built from the others only): Lakeshore, the general-purpose maker and the closest stand-in for an unknown tool, gets 0.71× its own speed and 0.71× its own chip at the median; our default is still above its own number in 20% of its rows (speed) and 18% (chip). That is not rare: the makers disagree by more than a quartile (Helical prints the fastest speeds and smallest chips, Harvey the biggest chips). P10 would be the lever if that share must come down.
- What the data cannot split: each helix angle is one maker's product line, the general-purpose tier is one maker (Lakeshore), and H is one maker (Helical), so those classes never reach two makers and the lookup opens them up; the classes that exist are the material-specific makers' (Harvey, Helical) by op, flutes and coating in M, N and P.
- Over 3124 cited end-mill rows, our generic default runs 0.75× the makers' spindle speed and 0.71× their feed per tooth at the median (in-sample: the classes are built from these rows, so under 1 is by construction).
- Per material group (median speed / chip, ours/theirs): P 0.72 / 0.57, M 0.82 / 0.70, K 0.77 / 0.62, N 0.77 / 0.80, S 0.62 / 0.65, H 1.41 / 0.97. H stays on the group table (one maker).
- Drills are unchanged by this (their own sourced model): 288 rows; all but 12 are rows our drill defaults were set from, so they check drift, not independence.
- Model checks against makers' own published adjustments: radial chip thinning matches Helical's and Harvey's formula (forge-tooling feeds tests); ball-nose effective diameter matches CNCCookbook's worked example; a maker's preset reproduces its own row inside the printed range for every row (Presets ON).

## The generic default: lower quartile by tool class

A tool with no maker preset takes its speed and chip from its **class**: material group × op class × maker tier × flute count × coating × helix band (kernel/forge-tooling/data/generic.toml, 53 classes, generated from these rows: `cargo run -p feeds-vs-makers -- --generic`). A class is written only with at least 10 rows from at least 2 makers; where the tool's own class has fewer, the lookup opens dimensions in this order: helix, tier, coating, flute count, op class (the class used is named in the value's note). The default is the class's **lower quartile (P25)**, not its median: a speed or chip that is too high breaks tools, one too low only costs time. The resolved value carries the class's min / P25 / median / max (`Resolved::spread`), so the user can push up knowingly.

What the makers' data supports: helix is one product line's in this data (Lakeshore 30°, Helical 35°/45°, Harvey 37°/42°), so no helix class has two makers; the general-purpose tier is Lakeshore's alone, so no general-purpose class has two makers either; H has one maker (Helical) and stays on the group table; K and S resolve at group level (any op). The classes that exist are the material-specific makers' (Harvey, Helical) by op, flutes and coating in M, N, P.

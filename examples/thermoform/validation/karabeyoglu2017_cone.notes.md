# karabeyoglu2017_cone: assumptions

- Mould: opening 200, depth 100 (paper, Fig. 2). Same lab/grade as Erdogan 2014; the moulds are taken as the same
  (karabeyoglu2017 Fig. 2 is the same render: s2_geom_case_dims_from_renders.csv karabeyoglu2017_cone base_diameter_virtual 146.4).
  Wall half-angle 15.0 deg, floor fillet 12 DERIVED (s2_geom_case_dims_from_renders.csv: erdogan2014_cone wall_half_angle 15.0,
  floor_fillet_radius 12; was base 150 and fillet 10 ASSUMED). Rim sharp.
- Sheet 150 C (thermal camera, 'approximately'); library HIPS Ogden (145 C fit) is in reach.
- Vacuum 0.096 MPa (720-730 mmHg). Flange 40 (blank 300 x 300).
- Measured rim values > t0 (s >= ~105 cone, >= ~135 cyl) are draw-in from the flange: a sticking model cannot reach them.

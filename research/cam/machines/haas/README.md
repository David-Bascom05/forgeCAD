## Sources (read 2026-11-23)

- **machinetoolindex.com/machines/haas-...** (one page per model): spec tables that restate
  haascnc.com, "verified 2026-10-02" per the pages. The main source. The facts we use are kept,
  restated as key/value pairs, in `machinetoolindex-2026-11-23.json`.
- **Haas Factory Outlet (Productivity Inc) "Mill Series Training Manual – Haas CNC Mill
  Programming"**, rev 04-2014, as hosted by UCSB
  (microfluidics.cnsi.ucsb.edu ... haas_mill_programming_manual.pdf): machine home and zero return
  (every axis to its extreme positive end), M06 behaviour, G04 P units, the M-code list.
  It covers the classic control. NGC may differ where noted.
- **Gerotech (HFO) "Installation Training for Haas NGC"** (resources.finalsite.net ...
  GerotechInstallationTrainingNGC-1.pdf): G187/settings 85/191, G234/G254/G255, "do not G28 G91
  with G234/G254 active, use G53", M73/M74 tool air blast, M83/M84 auto air gun.
- **Haas Automation UK** (haas.co.uk/machines/umc-750/) and the **Haas UMC-750SS data sheet**
  hosted by MTS (mtscnc.com/haas/images/pdf/DS_UMC750SS_US.pdf): cross-checks. Where they
  disagree with the main source the record cites both (`conflict`).
- NOT used: haascnc.com (Cloudflare bot challenge to automated clients; not worked around,
  including archive copies), diy.haascnc.com (502), haas.com (redirects to Bühler), memory.

## What is published, what is not

Published, cited per value: travels, nose-to-table, table/platter sizes, rapids, max cutting feed
(mills), spindle max rpm, peak power and torque points, taper/spindle nose, tool changer
pockets/chip-to-chip/max tool weight and diameter (and length where given), B/C travel and speed
(UMC), chuck size, swing, turning diameter/length, turret stations, C and live-tool speeds.

Estimated (basis in each cite): the power curve (min of torque x omega and peak power: never
above a published number), where the travel sits relative to the table (taken centred), axis
directions and which units move (the VF/UMC/turning-centre layouts are not stated on spec pages),
table thickness, chuck length.

Unknown (stand-ins that say which way they err): head/spindle-nose size (large), UMC tilt-axis
height (MRZP, set per machine) and the sign of +B, trunnion cradle and supports, turret disc size
and index time, lathe max cutting feed (taken equal to the rapid), minimum spindle speed (1 rpm),
DS-30Y sub-spindle travel and rapid, live-tool size limits. **Collision verdicts that involve these
bodies are only as good as the stand-ins.** The envelopes are drawn large where they matter (head,
turret), but without layout drawings that cannot be proven.

Accelerations: none published; the records carry none (time estimates assume infinite
acceleration and say so).

## Findings for CAM-MACHINE (research/cam/machines/FORMAT-GAPS.md)

- #8: a Haas M06 sends Z to machine zero by itself. forge-machine's changer moves nothing, which
  caused a false hit in the VF-2 sample (a longer second tool) and leaves the real Z-up move
  unchecked. The test posts an explicit G28 Z0 for now.
- #9: a linear axis lettered B (DS lathes' sub-spindle, unverified).

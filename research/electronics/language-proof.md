# Extending the .fg language proof for electronics

The proof lives in `research/forge-lang/lean`. It formalizes a core calculus and editability assumptions, with explicit counterexamples, a grammar model and differential checks against Rust. P1–P6 concern one meaning, totality under the stated evaluation model, driving sites, edit round trips, stable identities and an unambiguous grammar. `COVERAGE.md` inventories language surface and references the theorem or an explicit gap for each row. Some domains use a closed namespace. A document header parsed as an ordinary name and calls parsed by the existing grammar are an established extension pattern. That can save a grammar change. The meanings of new calls, their arguments and edits still need their own models. [Assumptions and P1–P6](https://github.com/David-Bascom05/forgeCAD/blob/d9d93a0aa2e2cc3a915a9f8fcd96e2d192be9542/research/forge-lang/ASSUMPTIONS.md) · [Coverage ledger](https://github.com/David-Bascom05/forgeCAD/blob/d9d93a0aa2e2cc3a915a9f8fcd96e2d192be9542/research/forge-lang/lean/COVERAGE.md) · [Existing document grammar examples](https://github.com/David-Bascom05/forgeCAD/blob/d9d93a0aa2e2cc3a915a9f8fcd96e2d192be9542/research/forge-lang/lean/ForgeLang/LL1/Documents.lean)

Two existing results govern the performance design. The control-dependency counterexample shows how a value can seem unchanged to a tracker while a branch changes its meaning. `OpMemo.memo_exact` proves fresh/cached agreement given a sound cache and a key covering everything the operation reads. `miss_wrong` exhibits failure when equal keys can yield different outputs. `verified_exact` checks the full key on a hash match. For an electrical rule the pad shape, layer, rule context, applicable exceptions and current zone fill can all be inputs. An index lookup that discovers no neighbours also reads something. The old proof gives the conditional theorem; the new work must establish its hypotheses for each new query. [Control counterexample](https://github.com/David-Bascom05/forgeCAD/blob/d9d93a0aa2e2cc3a915a9f8fcd96e2d192be9542/research/forge-lang/lean/ForgeLang/Counter/ControlUntracked.lean) · [Memoization theorems](https://github.com/David-Bascom05/forgeCAD/blob/d9d93a0aa2e2cc3a915a9f8fcd96e2d192be9542/research/forge-lang/lean/ForgeLang/OpMemo.lean)

| Proposed proof increment | Precise obligation | Counterexample / differential fixture to keep |
|---|---|---|
| Electronics document, types and names | Check the header and built-in family against the shared grammar; document scope and name-shadowing, unknown named-argument refusal, and behavior of non-electronics files. Define quantity dimensions plus typed references for logical pin, pad, net, side/layer, schematic point and board point. Elaboration yields either a well-typed model or a typed refusal | A misspelled clearance argument must not silently select a default. An angle cannot set a distance. A same-named pin of another sheet instance must not resolve. Existing parts may use `board` as a binding; test preservation before reserving any new word |
| Graphical and textual edit agree | For each operation with satisfied preconditions, parsing and elaborating its source patch equals executing the typed operation on the model, modulo the stated identity mapping. Refusal preserves the original document. Compose grouped patches atomically. For a purely presentational edit prove preservation of qualified electrical connectivity | Draw two crossing wires without a dot, move a label past them, then intentionally attach the junction. Only the last edit may merge these nets. Undo/redo returns the semantic model, IDs and intent. Run both authoring paths and reopen the files |
| Stable relations and advisory semantics | Define relation endpoints over definition plus occurrence and a validated pin map. Reannotation has an explicit rename mapping. Deriving or dismissing a suggestion cannot modify net equivalence, placement or a confirmed link. User confirmation can create a durable link. Ambiguity has a deterministic representation | Two identical channels sharing 3V3, nine capacitors on the same rail, or a package with multiple lands per logical pin. Changing selection order or moving a footprint must never silently reassign a confirmed owner |
| Witnesses, rules and units | Specify the finite predicate for one simple family. For round via lands prove the squared integer test equivalent to the declared distance inequality under coordinate bounds. Prove strict versus inclusive thresholds, side/layer applicability and permissioned exceptions separately. Readability checks prove the facts they report, such as a glyph intersecting a symbol, within a specified geometry model | Exact clearance equality, front and back with equal XY, missing courtyard, legitimate crossing, an accepted waiver with the wrong scope. Aesthetic preference, likely decoupling intent and human readability are empirical judgments; the provable parts are attribution, deterministic policy and measured evidence |
| Incremental update and every-frame coverage | Start with a finite set of pairs. If a single via moves and the rule is fixed, all pairs not incident to it keep their result. Replacing exactly the incident findings yields the fresh full set. Then prove spatial candidate inclusion and index update soundness before pruning. Extend to mutable selectors, net splits, zones and cross-document readers separately | Move into a previously empty cell; delete a bridge that disconnects a remote island; expand the clearance beyond the old search envelope; change a rule that activates a previously excluded pair. Compare the complete set including removed findings |
| Revision and cancellation | Define publication as a transition on base, overlay and provider coverage. A result may be marked current only if the revision or all validated inputs agree; a canceled partial run cannot certify sign-off. Event order cannot change the final complete verdict | A slow fill for revision A finishes after revision B; a drag gets canceled during a board flip; rule precedence changes and geometry stays byte-identical. Delay and reorder completions in replay |

Add syntax witnesses and family/argument rows where applicable, explicit semantic theorems or named gaps, small countermodels, and an executable reference oracle for the first EDA rule. Compare Rust text, graphical command and cold/incremental paths on generated edits. Preserve the repo's Lean build, axiom audit, `fgparse`/`fglex` comparisons and corpus digest gate. Lean and other independent tools belong in verification. Keep external libraries out of the production build. A timing guarantee comes from repeatable measurements on target hardware; equivalence and bounds can be proved within their models.

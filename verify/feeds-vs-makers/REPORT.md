# Our feeds and speeds against the tool makers' published numbers

Generated by `cargo run -p feeds-vs-makers` (verify/feeds-vs-makers). Ratios are ours / theirs; each cell is the median (10th–90th percentile, count). Ours (presets OFF): forge_tooling::resolve with the maker's own preset off, i.e. the generic default (the 10th percentile of the tool's class, below), at the maker's own ae/ap, no machine clamps; presets ON is its own section. Theirs: CAM-HAAS's cited raw rows (research/cam/tooling/raw/*.json; each row's URL is in rows.tsv). Ranges are taken at their middle.

## Summary

- "Are we the worst of all worlds by averaging manufacturer specs?" For a tool with no maker data the default was one pooled median per material group. It is now the **10th percentile (P10) of the tool's class** (material group × op class × maker tier × flutes × coating × helix, opened up where a class has under 10 rows or one maker), with the class's min/P10/P25/median/max shown next to the value so it can be pushed up knowingly. A tool with maker presets uses them first (next section but one).
- The independent check (each maker against classes built from the others only): Lakeshore, the general-purpose maker and the closest stand-in for an unknown tool, gets 0.56× its own speed and 0.60× its own chip at the median; our default is above its own number in 11% of its rows (speed) and 6% (chip) (target: about 5% or less).
- What the data cannot split: each helix angle is one maker's product line, the general-purpose tier is one maker (Lakeshore), and H is one maker (Helical), so those classes never reach two makers and the lookup opens them up; the classes that exist are the material-specific makers' (Harvey, Helical) by op, flutes and coating in M, N and P.
- Over 3124 cited end-mill rows, our generic default runs 0.60× the makers' spindle speed and 0.56× their feed per tooth at the median (in-sample: the classes are built from these rows, so under 1 is by construction).
- Per material group (median speed / chip, ours/theirs): P 0.58 / 0.50, M 0.66 / 0.65, K 0.63 / 0.48, N 0.54 / 0.51, S 0.77 / 0.60, H 1.41 / 0.97. H stays on the group table (one maker).
- Drills are unchanged by this (their own sourced model): 288 rows; all but 12 are rows our drill defaults were set from, so they check drift, not independence.
- Model checks against makers' own published adjustments: radial chip thinning matches Helical's and Harvey's formula (forge-tooling feeds tests); ball-nose effective diameter matches CNCCookbook's worked example; a maker's preset reproduces its own row inside the printed range for every row (Presets ON).

## The generic default: 10th percentile by tool class

A tool with no maker preset takes its speed and chip from its **class**: material group × op class × maker tier × flute count × coating × helix band (kernel/forge-tooling/data/generic.toml, 63 classes, generated from these rows: `cargo run -p feeds-vs-makers -- --generic`). A class is written only with at least 10 rows from at least 2 makers; where the tool's own class has fewer, the lookup opens dimensions in this order: helix, tier, coating, flute count, op class (the class used is named in the value's note). The default is the class's **10th percentile (P10)**, not its median (coordinator's decision, after P25 was still above the general-purpose maker's own number in ~1 row in 5): a speed or chip that is too high breaks tools, one too low only costs time, and the default applies only to tools with no maker data. The resolved value carries the class's min / P10 / P25 / median / max (`Resolved::spread`), so the user can push up knowingly.

What the makers' data supports: helix is one product line's in this data (Lakeshore 30°, Helical 35°/45°, Harvey 37°/42°), so no helix class has two makers; the general-purpose tier is Lakeshore's alone, so no general-purpose class has two makers either; H has one maker (Helical) and stays on the group table; K and S resolve at group level (any op). The classes that exist are the material-specific makers' (Harvey, Helical) by op, flutes and coating in M, N, P.
